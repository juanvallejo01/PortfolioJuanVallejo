01 ETHGlobal · ETHOnline 2026

SwipeFi

Swap and stake in one swipe — a Telegram Mini App on 1inch Aqua + Lido.

Problem
Staking from a stablecoin takes three separate transactions — swap, approve, stake. On mobile, that friction kills conversion.
Engineering call
Collapsed it into a single atomic transaction: USDC → ETH through 1inch Aqua liquidity, staked straight into Lido via executeAtomic(), with calldata ABI-encoded in viem against the official @1inch/aqua-sdk.
Result
One swipe instead of three transactions, validated end-to-end on a local Ethereum mainnet fork (Hardhat) before touching real funds.

02 Risk engineering · Python

Crypto Agent

An autonomous trading platform designed around failure, not optimism.

Problem
Most trading bots assume orders succeed — and blow up accounts when the exchange says otherwise.
Engineering call
Execution reconciliation that never trusts an order until the exchange confirms it, mandatory stop-loss / take-profit, a consecutive-loss circuit breaker and a daily-loss kill switch. API keys are zero-withdrawal and Fernet-encrypted per user.
Result
A multi-user Flask platform where every user runs an isolated Binance Spot bot (MA crossover + RSI, gated by a scikit-learn filter) with a live dashboard and Telegram alerts.

03 SaaS backend · TechNova

Urbanix

A residential-management SaaS, from paper and chat groups to one platform.

Problem
Residential complexes run visitors, residents, bookings and documents on paper and chat groups — no audit trail, no single source of truth.
Engineering call
A modular REST API (Node.js, Express, Prisma) over PostgreSQL with JWT-secured sessions, so each module — visitors, residents, common areas, documents, notifications — evolves independently.
Result
A full-stack SaaS (React + Tailwind) covering the day-to-day operations of a residential complex on one consistent data model.
