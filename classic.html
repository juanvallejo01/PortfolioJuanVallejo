Featured Projects

  • SwipeFi · ETHGlobal

    Problem: Staking from a stablecoin takes three separate transactions (swap, approve, stake) — too much friction for a mobile user.

    Decision: Collapsed the flow into one atomic transaction: USDC → ETH through 1inch Aqua liquidity, staked straight into Lido via executeAtomic(), with calldata ABI-encoded in viem against the official @1inch/aqua-sdk.

    Result: A Telegram Mini App where staking is a single swipe, validated end-to-end on a local Ethereum Mainnet fork (Hardhat) before touching real funds. Next.js, ethers.js/viem.

    Code

  • Crypto Agent

    Problem: Most trading bots assume orders succeed — and blow up accounts when they don’t.

    Decision: Built execution reconciliation that never trusts an order until the exchange confirms it, mandatory stop-loss/take-profit, a consecutive-loss circuit breaker and a daily-loss kill switch. API keys are zero-withdrawal and Fernet-encrypted per user.

    Result: A multi-user Flask platform where each user runs an isolated Binance Spot bot (MA crossover + RSI, gated by a scikit-learn filter) with a live dashboard and Telegram alerts. Python, CCXT.

    Code

  • Urbanix · SaaS backend

    Problem: Residential complexes manage visitors, residents, bookings and documents on paper and chat groups.

    Decision: Designed a modular REST API (Node.js, Express, Prisma) over PostgreSQL with JWT-secured sessions, so each module — visitors, residents, common areas, documents, notifications — scales independently.

    Result: A full-stack SaaS (React + Tailwind front end) covering the day-to-day operations of a residential complex.
